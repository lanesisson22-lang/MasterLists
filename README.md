# List

A simple, fast to-do list app for the web, Android and iOS. The app itself is plain HTML/CSS/JS in `www/` with no build step; [Capacitor](https://capacitorjs.com) wraps it as native apps in `android/` and `ios/`.

**Publishing to Google Play / the App Store: see [STORE_GUIDE.md](STORE_GUIDE.md).**

## Features

- Multiple lists: create, rename and delete them
- Add, complete, edit (double-click or ✎) and delete tasks
- Drag the ⠿ handle to reorder tasks (works with mouse and touch)
- Filter by All / Active / Done, and clear completed tasks
- Undo for deletes, and sharing a list through the share sheet
- Saves automatically in your browser (localStorage) and syncs across open tabs
- Light and dark mode follow your system setting
- Installable as an app on phone or desktop (PWA), and works offline
- In the native apps: data saved in native storage, haptic feedback, native share sheet, splash screen, and Android back button support

## Project layout

| Path | What it is |
|---|---|
| `www/` | The app (HTML, CSS, JS), the PWA manifest and service worker, and `privacy.html` |
| `android/`, `ios/` | Native projects generated by Capacitor |
| `assets/` | Source images for the app icon and splash screen (`npm run assets` regenerates them) |
| `capacitor.config.json` | App ID, name and native plugin settings |
| `.github/workflows/` | Builds the Android app; deploys `www/` to GitHub Pages |

## Run it

**In a browser:**

```sh
npm run serve        # then visit http://localhost:8000
```

**On a phone:** every push builds a test Android APK in the repo's **Actions** tab. For iOS, see [STORE_GUIDE.md](STORE_GUIDE.md).

**Native development** (requires Android Studio and/or Xcode):

```sh
npm ci
npm run android      # syncs www/ and opens Android Studio
npm run ios          # syncs www/ and opens Xcode (Mac only)
```
